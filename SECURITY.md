# Reporting a vulnerability in this skill

Report suspected security problems in the skill itself privately to franz@stratington.com. Include the skill revision, affected component, and a minimal description using synthetic data. Do not include credentials, production datasets, or a confidential client's code. Where possible, coordinate an appropriate disclosure plan before publishing sensitive exploit details.

This address is not an incident-response service or an authorization to test any system. No response time, bounty, professional service, or remediation commitment is promised by this policy, without limiting any obligation imposed by applicable law. Findings in a client's application should follow that client's authorized reporting process.
